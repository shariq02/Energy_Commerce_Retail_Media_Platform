# Energy Commerce & Retail Media Analytics Platform

A Germany-focused, enterprise-grade multi-domain analytics platform built on GCP, Databricks, and a modern open-source data stack. Combines energy-market conditions, weather, IoT/energy consumption, customer behaviour, commerce, and retail-media data into a single governed platform.

## Domains
- Energy Market
- Energy Retail
- IoT / Consumption
- Weather
- Customer
- Commerce
- Retail Media

## Tech Stack
GCP | BigQuery | Databricks | PySpark | Redpanda | PostgreSQL | Debezium | dbt | Dagster | Terraform | FastAPI | Grafana | Power BI | GitHub Actions
