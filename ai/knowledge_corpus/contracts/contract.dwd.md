# Contract: dwd

Deutscher Wetterdienst open hourly climate observations for a 28-station Germany-wide stratified network (population centres, climate regimes, energy / agriculture relevance, historical continuity), plus station / device / parameter metadata and a reported-missing-periods table. Static one-time acquisition from the DWD open-data server, no auth. Multi-decade archives -- the oldest measurement rows start 1893.
