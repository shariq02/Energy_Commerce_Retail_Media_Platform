# Contract: redispatch

German transmission-grid redispatch and countertrade measures -- each row is one instructed change to a generation unit's active-power feed-in to relieve a grid congestion or voltage problem. Static one-time acquisition. The acquired window is 2013-04 .. 2020-12, i.e. the OLD reporting regime BEFORE the NABEG 2.0 / Redispatch 2.0 switch of October 2021 -- this extract does not describe current redispatch practice.
