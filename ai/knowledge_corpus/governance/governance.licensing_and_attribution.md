# Governance: licensing and attribution

Every source is used within its own licence terms. The licence and any attribution, share-alike or non-commercial condition is verified for each dataset before staging and is recorded in the data contract. A source whose licence cannot be confirmed as compatible with the non-commercial portfolio framing is not staged.

Most German official sources use open-data terms such as DL-DE-BY or CC BY. They require source attribution. The attribution requirements also apply to any public, sanitised version of the documentation.

GA4 is a public demo export, used within Google's terms. It is never presented as a live Analytics property that this project owns.

OpenStreetMap data (ODbL) needs the attribution "OpenStreetMap contributors". Share-alike applies to derived databases. Any external publication of OpenStreetMap-derived data must first be confirmed as ODbL-compliant.
